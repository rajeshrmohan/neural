⚡ Neural Network Forward Pass
Step 1
📥 Input Layer
Your drawing is resized to a 20×20 pixel grid and centered. Each pixel becomes one of 400 input neurons (0 = black, 1 = white).
Step 2
🔍 Hidden Layer 1
64 neurons detect simple features — edges, curves, and corners. Each neuron combines all 400 inputs with learned weights, then applies sigmoid activation.
Step 3
🧩 Hidden Layer 2
32 neurons combine the features from Layer 1 into higher-level patterns — loops, strokes, and shapes that distinguish different digits.
Step 4
🎯 Output Layer
10 neurons — one per digit (0–9). Each outputs a confidence score. The highest score is the network's prediction.
